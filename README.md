# meta-harness

Research and tooling for the **operator-OS layer** above AI coding agents: how
products in that category define agents, assign work, and isolate permissions while
keeping the underlying runtime swappable.

## Status

- **Current:** Astro notebook plus draft catalogs (`FEATURES.md`, `FEATURE_MAP.md`,
  `LANDSCAPE.md`, `CANDIDATES.md`)
- **Planned:** versioned capability spec, knowledge graph, decision engine, CLI, and
  API — see [`ROADMAP.md`](./ROADMAP.md)

## Definition (E)

An operator OS for a fleet of agents — roles, work, permissions, walk-away operation —
with a swappable harness underneath.
